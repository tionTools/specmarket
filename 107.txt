Purpose:
1. UserAuthenticationJWT now uses the existing immediate transport retry in both NovaPay Edge Functions. This is specifically for the NovaPay 120-second historical refresh-token grace period when a successful rotation response is lost in transit.
2. Saving the newly rotated refresh token/certificate/JWT to Vault is retried once. Repeating the same save payload is idempotent and protects against a lost/transient Supabase RPC response.
3. Rotation stage logs contain no token/certificate values.
4. Bank statement UI displays NovaPay API status/title details already returned by the Edge Function.
5. Auth tests cover permanent save failure, transient save recovery, and rejection of a rotated JWT without a usable expiry.
