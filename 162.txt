SpecMarket — Patch 162: сохранять только изменённые позиции каталога цен

Репозиторий: tionTools/specmarket.
Base main при подготовке: d787fc329c39d71ecf3ee7fa69cb58b55d51a535.
Файлы: chatgpt-patches/162.patch и chatgpt-patches/162.txt.
Код: только src/pages/PricesView.vue. Не менять cron, Edge Functions, миграции, заказы, Patch 161.

Причина, подтверждённая исходным кодом: persistCatalog() для любого save() проходит весь items[] и отправляет UPDATE для каждой позиции, даже без изменений. Пока выполняется проход, новые save() ставят saveRequested=true, и цикл начинает полный проход повторно. 897 PATCH / 195 ID за 88 с совместимы с этим механизмом; точная последовательность действий пользователя по API-логам не восстанавливается.

Исправление: хранить JSON-снимок последнего подтверждённого payload для каждой remoteId; инициализировать при успешной загрузке; сохранять только строки, у которых изменились передаваемые поля или позиция. Для нового товара — INSERT с прежней защитой удаления в процессе; после успеха фиксировать снимок. При изменении во время незавершённого запроса следующий проход должен увидеть новую версию; нельзя помечать текущую живую строку как сохранённую, только payload, действительно отправленный. Действующие изменения структуры/порядка таблицы сохраняются; при reorder обновлять все реально сдвинутые position. Не обновлять неизменённые товары, даже если save() вызван много раз. Проверять ошибки записи, показывать ошибку и возможность повтора. Ошибку SELECT не трактовать как пустую БД/причину импортировать весь исходный каталог. При ошибке загрузки кнопка должна повторять именно чтение, не запускать save() по локальному каталогу.
