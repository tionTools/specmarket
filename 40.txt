Patch 40 — выбор позиции из «Цен» при создании/редактировании ручного заказа

База для подготовки: актуальный main на момент создания Patch 40 = c135b54363bec2fa185d0180c803b2d74f5df494.

ВАЖНО: Patch 40 не заменяет Patch 39. Patch 39 исправляет отдельное падение structuredClone при сохранении ручного заказа. Если Patch 39 ещё не применён в main, сначала примени Patch 39 по его инструкции, затем Patch 40. Patch 40 специально не меняет cloneOrder(), чтобы задачи не смешивались.

Цель:
В форме ручного заказа пользователь должен иметь возможность выбрать товар прямо из раздела «Цены». После выбора в незаконченный заказ должны вернуться название позиции и себестоимость из прайса, а количество, размер, цена продажи и остальные введённые данные заказа должны сохраниться без изменений.

Требуемая логика:
1. В карточке каждого товара в форме нового/редактируемого ручного заказа добавить кнопку:
   - «Выбрать из цен», если priceItemId ещё нет;
   - «Сменить из цен», если позиция уже выбрана из прайса.
2. Перед переходом на /prices сохранить в sessionStorage:
   - весь текущий orderDraft;
   - editingManualOrderId;
   - id конкретного товара, для которого выбирается прайс.
   Форму можно закрыть на время перехода.
3. Открыть /prices в отдельном режиме ручного выбора через query manualSelect=1 и manualProductId=<id товара>.
4. В PricesView в этом режиме:
   - не использовать marketplace linkMode и crm_product_price_links;
   - поиск должен оставаться обычным пустым поиском по каталогу;
   - у обычных строк прайса вместо удаления должна быть кнопка «Выбрать»;
   - группы не выбираются;
   - строка должна иметь remoteId, потому что выбранный price_item_id потом сохраняется в crm_order_items;
   - существующий режим «Привязать» для Prom/Epicentr/Kasta не сломать и не менять его смысл.
5. При выборе строки сохранить в sessionStorage:
   - productId;
   - priceItemId = item.remoteId;
   - name = item.name;
   - costUsd = item.usd ?? 0;
   - costUah: если item.usd заполнен, item.usd * текущий usdRate; иначе item.costUah ?? 0.
6. Вернуться на / с query returnManualDraft=1.
7. HomeView должен восстановить сохранённый orderDraft, editingManualOrderId и снова открыть диалог ручного заказа.
8. В выбранном товаре обновить только:
   - name;
   - priceItemId;
   - costUsd;
   - cost;
   - costManual = false.
   НЕ менять:
   - product.id;
   - size;
   - quantity;
   - price продажи;
   - royalty;
   - данные покупателя;
   - площадку/статус;
   - доставку/ТТН;
   - расходы и остальные товары заказа.
9. Если пользователь на странице «Цены» нажал «К заказам», не выбрав строку, вернуть его в ту же заполненную форму ручного заказа без изменений.
10. После восстановления удалить временные ключи sessionStorage, чтобы старый черновик не всплывал повторно.
11. Уже существующее поле priceItemId должно продолжить сохраняться в crm_order_items.price_item_id через существующий serialize/persist поток. Новую миграцию для этого не делать.
