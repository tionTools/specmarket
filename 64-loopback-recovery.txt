2. Причина текущей остановки
Ошибка `java.io.IOException: Unable to establish loopback connection` на Windows может возникать внутри sandbox/agent runtime при Java NIO/Gradle IPC и не означает, что Patch 64 или Android-код неисправны. Не меняй код проекта ради этой ошибки и не устанавливай ещё один JDK.

New-Item -ItemType Directory -Force -Path $jtmp | Out-Null
$oldTemp = $env:TEMP

Загрузи credentials без вывода значений:
```powershell
$repoRoot = (Get-Location).Path
$signingDir = Join-Path (Split-Path -Parent $repoRoot) 'android-signing'
$keystore = Join-Path $signingDir 'orders-release.jks'
$credentialsFile = Join-Path $signingDir 'orders-release-credentials.txt'
if (!(Test-Path $keystore) -or !(Test-Path $credentialsFile)) { throw 'Existing release signing files not found; stop without regenerating them.' }
$cfg = (Get-Content -Raw $credentialsFile | ConvertFrom-StringData)
$env:ORDERS_RELEASE_STORE_FILE = $keystore
$env:ORDERS_RELEASE_STORE_PASS = $cfg.password
$env:ORDERS_RELEASE_ALIAS = $cfg.alias
$env:ORDERS_RELEASE_KEY_PASS = $cfg.password
```
