- Кнопка «Реестр печати» мгновенно показывает снимок известных активных нераспечатанных заказов с ТТН. Не ждёт проверки всех отсутствующих ТТН; существующее автоматическое сохранение printCheckedAt выполняется после показа окна, а пока сохраняет — действия с отметками заблокированы.
- В окне явно видно число отсутствующих ТТН; их заказы НЕ попадают в список до проверки.
- Внутри: «Проверить ТТН» по явному запросу, targeted sync Prom/Epicentr/Kasta пачками по 4 с AbortSignal.timeout(12s) для каждого API запроса и отсечкой новых пачек после 30s. Прогресс, ошибки, количество непройденных заказов.
- Новые обнаруженные ТТН не добавляются молча: показывается «Обновить реестр», добавление только после сохранения printCheckedAt.
- Все прежние суммы, статусы, истории, галочки и финансовые расчёты сохраняются, без изменений SQL/Edge/cron.
