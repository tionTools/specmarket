Purpose:
- No automatic bank refresh.
- Both Edge Functions return cached data when POST body does not contain {"refresh":true}.
- A manual refresh calls the bank, stores balance + last 7 days of incoming receipts + updated time in public.bank_account_cache, then returns that data.
- Monobank selects exactly one UAH account with type=fop and uses MONOBANK_API_TOKEN server-side.
- Monobank manual refresh has a 90-second server cooldown to respect API rate limits.
- NovaPay uses the existing JWT rotation flow, existing Vault RPCs, and the Patch 92 rotation lock. It reads GetAccountRest + GetAccountExtract for the last 7 days.
- NovaPay refresh token/public certificate/login are never returned or logged.
- bank_account_cache is readable only by authenticated non-guest users; writes are service-role only.
- The migration seeds rows for monobank and novapay.

Important NovaPay diagnostic behavior:
If GetAccountExtract returns documents but no incoming receipts are recognized, novapay-data returns only diagnostics.documentCount and diagnostics.sampleKeys (field names only, no transaction values). This is temporary-safe schema detection for the first live smoke test; do not redesign it before seeing the real response.
