Patch 81 — статус изменения адреса должен быть зелёным как доставка в пути

База main: b10f3adccd9c4b8960786f6eaa5efd5a43cd55b8

Причина подтверждена в текущем HomeView.vue: orderStatusTone() считает зелёными только normalized accepted/in_transit/ready_for_pickup/delivered. Статус Nova Poshta «Змінено адресу» приходит с trackingNormalizedStatus=unknown и не совпадает с текущим fallback-regex; поэтому функция падает в default blue. Нормализованный forwarding также не входит в зелёный список.

Scope:
- src/pages/HomeView.vue

Что должно получиться:
- «Змінено адресу» / изменение адреса / переадресация у перевозчика окрашиваются зелёным, как статус «в дороге».
- normalized forwarding окрашивается зелёным.
- raw carrier fallback применяется также при trackingNormalizedStatus=unknown, а не только при пустом normalized status.
- Текст статуса не менять.
- Красные return/cancel statuses не менять.
- Полученная доставка: для не-Prom остаётся orange; для Prom остаётся green до подтверждения завершения на площадке.
- Обычный неизвестный статус вроде «Очікує оформлення» не должен автоматически становиться зелёным.
- Никаких изменений backend/Supabase/Android.

Проверенные логические случаи:
- unknown + «Змінено адресу» -> green
- forwarding + «Переадресовано» -> green
- in_transit + «Відправлення у дорозі» -> green
- empty + «Змінено адресу» -> green
- unknown + «Очікує оформлення» -> не green
