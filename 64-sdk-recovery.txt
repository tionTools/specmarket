Сначала проверь, не указан ли SDK в исходном локальном `android\local.properties` (этот файл обычно gitignored):
```powershell
$repoRoot = (Get-Location).Path
$localProps = Join-Path $repoRoot 'android\local.properties'
$sdk = $null
if (Test-Path $localProps) {
    $sdkLine = Get-Content $localProps | Where-Object { $_ -match '^sdk\.dir=' } | Select-Object -First 1
    if ($sdkLine) {
        $sdk = ($sdkLine -replace '^sdk\.dir=', '') -replace '\\\\','\'
    }
}
```

Если `$sdk` не найден или путь не существует, проверь по порядку, не выводя лишние данные:
```powershell
$candidates = @(
    $env:ANDROID_HOME,
    $env:ANDROID_SDK_ROOT,
    (Join-Path $env:LOCALAPPDATA 'Android\Sdk'),
    (Join-Path $env:USERPROFILE 'AppData\Local\Android\Sdk')
) | Where-Object { $_ -and (Test-Path $_) } | Select-Object -Unique
if (!$sdk -or !(Test-Path $sdk)) { $sdk = $candidates | Select-Object -First 1 }
if (!$sdk -or !(Test-Path $sdk)) { throw 'Existing Android SDK not found. Stop without changing project, keystore or Secrets.' }
```
