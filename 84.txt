Обязательная процедура Codex

1. Не трогать dirty main, AGENTS.md и пользовательские untracked-файлы.
2. Fetch refs и подтвердить, что `origin/main` всё ещё ровно:
   `61b550c16b8950b453738f089ccb978358c3aaa0`
   Если main изменился — STOP и сообщить новый SHA; Patch 84 не применять вслепую.
3. Создать отдельный чистый worktree от указанного base.
4. Получить `84.patch` byte-for-byte из `origin/chatgpt-patches` и проверить SHA-256:
   `a5323dc153b0ff7e2922960ce0d25fea3a569ec63a851847ed94f5c5c1e5086b`
5. Выполнить `git apply --check 84.patch`.
6. Только при PASS выполнить `git apply 84.patch`.
7. Собрать PNG из четырёх asset parts, не добавляя сами `.b64.part*` в worktree/main. Пример PowerShell из корня worktree:

```powershell
$parts = 1..4 | ForEach-Object {
  (git show "origin/chatgpt-patches:84-icon.b64.part$_" | Out-String).Trim()
}
$bytes = [Convert]::FromBase64String(($parts -join ''))
$iconPath = 'android/app/src/main/res/drawable-nodpi/ic_orders_crm.png'
[IO.Directory]::CreateDirectory((Split-Path $iconPath -Parent)) | Out-Null
[IO.File]::WriteAllBytes($iconPath, $bytes)
(Get-FileHash -Algorithm SHA256 $iconPath).Hash.ToLowerInvariant()
```
