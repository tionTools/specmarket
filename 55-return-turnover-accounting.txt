PATCH 55 — исправить оборот при возвратах

Источник истины: текущий main, HEAD должен соответствовать origin/main. На момент подготовки патча main = 17c231b24c4ad0f7dc7a01368be9c490be90a595.

Цель:
- физически отправленный заказ с сигналом отмены/возврата НЕ должен исчезать из оборота, пока возврат не принят в CRM;
- до принятия возврата в обороте остаётся вся оставшаяся сумма заказа;
- после полного `Принять возврат` заказ исключается из оборота, потому что lifecycle = return_completed и net sale = 0;
- при частичном принятом возврате заказ остаётся в обороте только на оставшуюся сумму;
- отмена до физической отправки по-прежнему не входит в оборот;
- правило должно работать одинаково для Prom / Epicentr / Kasta / Р/С / Сайт, без отдельного исключения только для Kasta.
