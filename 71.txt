Что меняет Patch 71
- Общий список: фон приложения заметно темнее белых карточек; карточки компактнее и визуально разделены.
- В карточке приоритет: площадка + статус + сумма, затем крупно получатель и телефон, затем товары, доставка, внизу дата/время и вторичный номер заказа.
- Получатель/телефон берутся прежде всего из delivery.recipient / delivery.recipientPhone, с fallback на customer / phone.
- Предотправочные отмены скрываются из основного списка по той же модели, что Web CRM: отмена/return-signal без фактического движения посылки скрыта; возвраты после движения остаются.
- Локальный поиск открывается маленькой лупой в верхней панели; ищет по имени/фамилии, обоим телефонам, номеру заказа, ТТН, площадке, товару, размеру и данным доставки; работает по сохранённым данным без Realtime.
- Большой баннер про ручное обновление убран; при отсутствии Realtime остаётся только маленький статус «Офлайн · сохранённые данные».
- Offline-first усилен: при неожиданно пустой памяти перед сетевым refresh повторно поднимается дисковый cache; cache хранит last-known-good backup и предпочитает непустой снимок.
- Экран заказа: компактная шапка; затем Получатель -> Товары -> Доставка -> Оплата -> Дополнительная информация.
- Доставка больше не дублируется сверху; технические firstSeenAt/lastSeenAt удалены из UI.
- История отправлений показывается только если записей больше одной и раскрывается по нажатию.
- Viber/Telegram используют телефон фактического получателя и сохраняют прежние deep links/цвета.
- Launcher/round icon заменён на чёрную иконку с цветным кольцом и огнём по утверждённому образцу.
- Realtime, marketplace acceptance, notification dedupe и серверная архитектура не меняются.
