Purpose:
Add non-secret diagnostic logging for NovaPay UserAuthenticationJWT request_ref and response_ref so failed/successful auth attempts can be correlated with NovaPay support.

Behavior:
- generate auth request_ref once per actual UserAuthenticationJWT attempt;
- log: NovaPay auth request_ref: <value>;
- after a parsed UserAuthenticationJWT result is received, log: NovaPay auth response_ref: <value>;
- if response_ref is absent, log "missing";
- response_ref is logged before logical API error handling, so a NovaPay logic_error can still be correlated;
- transport/parse failures may naturally have no response_ref;
- existing fingerprint diagnostics remain unchanged;
- no refresh token, certificate, JWT, login, or other secret is logged;
- no auth retry, lock, persistence, SOAP timeout, parser, schedule, frontend, DB or Vault behavior changes.
